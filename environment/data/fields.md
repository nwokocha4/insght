# Input field description

The task has one input:

- `reference/zhao2026_camera_trap_diversity.pdf` is the complete published data
  paper. Its Table 1 lists mammal detections and relative abundance indices;
  Table 2 lists altitude-stratified alpha-diversity metrics. The cover page
  carries the title, DOI, journal, and publication year.

There are no case directories, image trees, roster files, or per-frame metadata.
The PDF is the sole evidence source and is available offline.
